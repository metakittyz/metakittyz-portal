# metakittyz-portal

## [`eternal-ruler/`](eternal-ruler/) — Eternal Ruler

A gateway app for opening and strengthening the connection between you and your higher self.
Mind, body, and spirit: the Hot & Cold rating system, an awakening journal, guided State Stacks for
reaching your maximum working state, a voice room for recording reassurance in your own voice, a
manifestation forge, a Codex of neuroscience / health / spiritual practice, and a mentor
marketplace. Local-first React + Vite, no backend, no accounts.

18+. A self-experiment, not therapy. See [`eternal-ruler/README.md`](eternal-ruler/README.md).

```bash
cd eternal-ruler && npm install && npm run dev
```
